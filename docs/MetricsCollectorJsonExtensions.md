# MetricsCollectorJsonExtensions

> **Status: source file removed.** `Diagnostics/MetricsCollectorJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `MetricsCollector` in the `SkiaSharpChartEngine.Diagnostics` namespace. The extensions convert a `MetricsCollector` instance to a JSON string and back, using camelCase property names and string-based enum values.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`.
- A `JsonStringEnumConverter` using `JsonNamingPolicy.CamelCase`.

## API

### `public static string ToJson`

Serializes a `MetricsCollector` instance to a JSON string. When `indented` is `true`, the method serializes with a copy of the shared options that has `WriteIndented` enabled. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`MetricsCollector`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the `MetricsCollector`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static MetricsCollector? FromJson`

Deserializes a JSON string to a `MetricsCollector` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `MetricsCollector?`: The deserialized instance, or `null` if the JSON represents a null value.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty.
- `JsonException`: Thrown when the JSON is invalid or cannot be deserialized.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to a `MetricsCollector` instance. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`MetricsCollector?`, `out`): Receives the deserialized instance, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty.

---

## Usage

```csharp
using SkiaSharpChartEngine.Diagnostics;

MetricsCollector collector = /* resolved from DI or created with an ILogger<MetricsCollector> */;

string compact = collector.ToJson();
string indented = collector.ToJson(indented: true);

MetricsCollector? restored = MetricsCollectorJsonExtensions.FromJson(compact);

if (MetricsCollectorJsonExtensions.TryFromJson(indented, out var parsed))
{
    // parsed is the deserialized instance
}
```

## Notes

- `ToJson` and `FromJson` are the only public entry points. Whitespace-only input is not rejected by the guard (it is neither `null` nor empty), so it reaches `JsonSerializer`, which throws `JsonException`. `TryFromJson` returns `false` for it.
- `TryFromJson` only handles `JsonException`. Argument validation errors still propagate.
- `MetricsCollector` exposes no public properties. Its collected data lives in private fields, so `ToJson` produces an empty object (`{}`) and does not capture recorded metrics. The metric data types (`MetricsContext`, `OperationMetrics`, `ExecutionMetric`, `MetricsSummary`) have their own public properties, but they are not serialized through these helpers.
- `MetricsCollector` requires an `ILogger<MetricsCollector>` in its constructor and has no parameterless constructor. Round-tripping through `FromJson` or `TryFromJson` is therefore not expected to rebuild a working collector. This was determined by reading the type, not by running a round-trip test.
