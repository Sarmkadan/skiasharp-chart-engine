# XmlChartSerializerJsonExtensions

> **Status: source file removed.** `Serializers/XmlChartSerializerJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` helpers for `XmlChartSerializer`. The extensions convert an `XmlChartSerializer` instance to a JSON string and read one back, using camelCase property names.

Despite the name, these helpers have nothing to do with the XML format. They do not convert charts to or from XML, and they do not touch the XML content that `XmlChartSerializer` produces. For the actual XML round-trip of a `Chart`, see [XmlChartSerializer](XmlChartSerializer.md).

The helpers were never useful for persisting chart data. `XmlChartSerializer` keeps no public state (its only fields are a private `ILogger` and a private `XmlSerializer`), so the JSON form is always an empty object.

## Build status when the file existed

The project file excludes the whole folder from compilation with `<Compile Remove="Serializers/**/*.cs" />`, so this file was never built. The class it extended, `XmlChartSerializer`, is in the same `SkiaSharpChartEngine.Serializers` namespace, so no `using` directive was needed.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance with `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`. Nothing else is configured: `WriteIndented` is off by default, nulls are not ignored, and no `TypeInfoResolver` is set, so the default reflection-based resolver is used. The helpers are therefore not compatible with trimmed or AOT-published output without a source-generated context.

## API

### `public static string ToJson`

Serializes an `XmlChartSerializer` instance to a JSON string. When `indented` is `true`, it serializes with a new copy of the shared options with `WriteIndented` set to `true`. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`XmlChartSerializer`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation. Because the class has no public properties, this is always `{}`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static XmlChartSerializer? FromJson`

Deserializes a JSON string to an `XmlChartSerializer` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `XmlChartSerializer?`: The deserialized instance, or `null` if `json` is empty or the literal JSON value `null`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `JsonException`: Thrown when `json` is not valid JSON.
- `InvalidOperationException`: Thrown for a valid JSON object such as `{}`. The class has no parameterless constructor, and its only constructor parameter (`ILogger<XmlChartSerializer>`) cannot bind to any JSON property, so System.Text.Json rejects the type.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to an `XmlChartSerializer` instance. Catches `JsonException` and reports failure through the return value.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`XmlChartSerializer?`, `out`): Receives the deserialized instance. It is `null` when the method returns `false`.

**Return Value**
- `bool`: `true` if deserialization completes without a `JsonException`; otherwise, `false`. An empty `json` returns `false`.

  As with `FromJson`, the literal `null` is treated as success, and `TryFromJson("null", out var v)` returns `true` with `v` set to `null`. A valid object such as `{}` is not caught, so `InvalidOperationException` propagates out of this method.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `InvalidOperationException`: Thrown for a valid JSON object such as `{}` (see `FromJson`).

---

## Usage

`ToJson` is an extension method, so it is called on an instance. `FromJson` and `TryFromJson` are static methods on the class and are called through it.

```csharp
var serializer = new XmlChartSerializer(logger);

// Serialize (always "{}" for this class)
string json = serializer.ToJson();
string indentedJson = serializer.ToJson(indented: true);

// Deserialize: fails for "{}" because the class cannot be constructed from JSON
XmlChartSerializer? restored = XmlChartSerializerJsonExtensions.FromJson("null"); // returns null

if (XmlChartSerializerJsonExtensions.TryFromJson(json, out var value))
{
    // Not reached for "{}": InvalidOperationException propagates out of TryFromJson
}
```

The `ILogger` dependency is not part of the JSON, so a deserialized instance would need a logger supplied some other way. System.Text.Json has no way to provide one.
