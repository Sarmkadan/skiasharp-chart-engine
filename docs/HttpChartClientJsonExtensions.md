# HttpChartClientJsonExtensions

> **Status: source file removed.** `Integration/HttpChartClientJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `HttpChartClient` in the `SkiaSharpChartEngine.Integration` namespace. The extensions write only the client's base URL to JSON and rebuild a client from that URL. The logger, serializer, and `HttpClient` are not part of the JSON and must be supplied separately.

The `Integration/` folder is excluded from the build by `<Compile Remove="Integration/**/*.cs" />` in `skiasharp-chart-engine.csproj`, so this file was never compiled into the library.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, built from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`.
- `ReferenceHandler` set to `ReferenceHandler.IgnoreCycles`.
- `PropertyNameCaseInsensitive` set to `true`.

The JSON payload is a private nested type, `HttpChartClientConfiguration`, which has one property, `BaseUrl`. The payload looks like this:

```json
{"baseUrl":"https://charts.example.com"}
```

## API

### `public static string ToJson(this HttpChartClient value, bool indented = false)`

Serializes the client's `BaseUrl` into a JSON string. When `indented` is `true`, the method serializes with a copy of the shared options that has `WriteIndented` enabled. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`HttpChartClient`, `this`): The client to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the client's base URL configuration.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static HttpChartClient? FromJson(string json)`

Deserializes a JSON string into an `HttpChartClient`. The configuration is mapped to a new client with `new HttpChartClient(BaseUrl, null!, null!)`.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `HttpChartClient?`: The rebuilt client, or `null` if the JSON represents a null value.

**Exceptions**
- `ArgumentException`: Thrown when `json` is `null` or empty.
- `InvalidOperationException`: Thrown when the decoded `BaseUrl` is `null`, empty, or whitespace. Thrown inside the `try` block, but `FromJson` only catches `JsonException`, so it propagates.
- `JsonException`: Thrown when the JSON is invalid or cannot be deserialized. Caught and rethrown with the message `"Failed to deserialize HttpChartClient configuration"` and the original exception as `InnerException`.
- `ArgumentNullException`: Thrown for any valid, non-empty `BaseUrl`, because the constructor receives `null` logger and serializer arguments. See Notes.

---

### `public static bool TryFromJson(string json, out HttpChartClient? value)`

Attempts to deserialize a JSON string into an `HttpChartClient`. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`HttpChartClient?`, `out`): Receives the rebuilt client, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentException`: Thrown when `json` is `null` or empty.
- `InvalidOperationException`: Thrown when the decoded `BaseUrl` is `null`, empty, or whitespace. Not caught.
- `ArgumentNullException`: Thrown for any valid, non-empty `BaseUrl`, for the same reason as `FromJson`. Not caught.

---

## Usage

```csharp
using Microsoft.Extensions.Logging;
using SkiaSharpChartEngine.Integration;

var client = new HttpChartClient("https://charts.example.com/", logger, serializer);

string compact = client.ToJson();
string indented = client.ToJson(indented: true);

// Intended usage, as documented for the last committed version.
// In that version this call throws ArgumentNullException (see Notes).
HttpChartClient? restored = HttpChartClientJsonExtensions.FromJson(compact);

if (HttpChartClientJsonExtensions.TryFromJson(indented, out var parsed))
{
    // parsed holds a client built from the saved base URL
}
```

## Notes

- **Dependencies are not restored.** `FromJson` and `TryFromJson` only recover `BaseUrl`. Callers who need logging or a custom `IChartSerializer` must create the client themselves.
- **Valid input fails with `ArgumentNullException`.** The constructor throws when the logger or serializer is `null`, and the extensions pass `null!` for both. Every well-formed, non-blank `BaseUrl` therefore fails in `FromJson` and `TryFromJson`. `TryFromJson` does not catch this, so it throws instead of returning `false`. Only malformed JSON produces `false` or `JsonException`. This is a defect in the removed version, and it is the main reason the file was not usable.
- **`BaseUrl` is normalized by the constructor.** Trailing slashes are removed (`TrimEnd('/')`), so `ToJson` output contains the trimmed value.
- **Blank URLs are rejected at the mapping step.** `ToHttpChartClient` throws `InvalidOperationException` before the constructor runs. `TryFromJson` does not catch it.
- **Cycle handling and case-insensitive names are configured but unused.** The payload has no reference cycles and only one property, so `ReferenceHandler.IgnoreCycles` and `PropertyNameCaseInsensitive` have no effect on the current payload.
- `HttpChartClient` owns an `HttpClient` that is not part of the JSON. Dispose each client created by the caller.
