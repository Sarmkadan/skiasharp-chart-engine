# MetricsAggregatorWorkerJsonExtensions

> **Status: source file removed.** `Workers/MetricsAggregatorWorkerJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `MetricsAggregatorWorker` in the `SkiaSharpChartEngine.Workers` namespace. The extensions convert a `MetricsAggregatorWorker` instance to a JSON string and back, using camelCase property names, no null values, and cycle-safe reference handling.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance built from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`.
- `ReferenceHandler` set to `ReferenceHandler.IgnoreCycles`.

## API

### `public static string ToJson`

Serializes a `MetricsAggregatorWorker` instance to a JSON string. When `indented` is `true`, the method serializes with a copy of the shared options that has `WriteIndented` enabled. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`MetricsAggregatorWorker`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the `MetricsAggregatorWorker`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static MetricsAggregatorWorker? FromJson`

Deserializes a JSON string to a `MetricsAggregatorWorker` instance. Catches `JsonException` and returns `null` instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `MetricsAggregatorWorker?`: The deserialized instance, or `null` if deserialization fails with a `JsonException`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to a `MetricsAggregatorWorker` instance. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`MetricsAggregatorWorker?`, `out`): Receives the deserialized instance, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty.

---

## Usage

```csharp
using SkiaSharpChartEngine.Workers;

MetricsAggregatorWorker worker = /* resolved from DI or created with an ILogger<MetricsAggregatorWorker> */;

string compact = worker.ToJson();
string indented = worker.ToJson(indented: true);

MetricsAggregatorWorker? restored = MetricsAggregatorWorkerJsonExtensions.FromJson(compact);

if (MetricsAggregatorWorkerJsonExtensions.TryFromJson(indented, out var parsed))
{
    // parsed is the deserialized instance
}
```

## Notes

- `ToJson` and `FromJson` are the only public entry points besides `TryFromJson`. The private `ToJson(value, indented, options)` overload is an implementation detail and is not callable from outside the class.
- Whitespace-only input is not rejected by the guard (it is neither `null` nor empty), so it reaches `JsonSerializer`, which throws `JsonException`. `TryFromJson` returns `false` for it, and `FromJson` returns `null`.
- `TryFromJson` and `FromJson` only handle `JsonException`. Argument validation errors still propagate.
- `MetricsAggregatorWorker` exposes no public properties. Its state lives in private fields (`_metrics`, `_timer`, `_aggregationInterval`, `_isRunning`), and `MetricsAggregatedEventArgs` is exposed only as an event, which is not serialized. `ToJson` therefore produces an empty object (`{}`) and does not capture recorded metrics. The data types `MetricData`, `MetricStatistics`, and `AnomalyAlert` have their own public properties, but they are not serialized through these helpers.
- `MetricsAggregatorWorker` requires an `ILogger<MetricsAggregatorWorker>` in its constructor and has no parameterless constructor. Round-tripping through `FromJson` or `TryFromJson` is therefore not expected to rebuild a working worker. Because the failure is probably not a `JsonException`, it may propagate past the catch block. This was determined by reading the type, not by running a round-trip test.
- The `Workers/**/*.cs` pattern was excluded from the build in `skiasharp-chart-engine.csproj`, so the removed file was not compiled in the current configuration either.
