# PdfReportOptions

Options class that controls the page layout, font sizes, colours and footer of a PDF report generated by `PdfReportGenerator`. Every property has a default, so `new PdfReportOptions()` produces an A4 white page with a "Chart Report" title and no further configuration.

Defined in `Reports/PdfReportOptions.cs` (namespace `SkiaSharpChartEngine.Reports`). The class is `sealed` and has no base class or interface.

## Overview

The options object is a plain mutable bag of settings. Most properties are auto-implemented. Three dimension properties (`PageWidth`, `PageHeight`, `Margin`) are backed by private fields and validate their input, so assigning an invalid value throws `ArgumentOutOfRangeException` at the point of assignment rather than failing later during rendering.

Units are PDF points unless stated otherwise (1 pt = 1/72 inch).

## Properties

### Content

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `Title` | `string` | `"Chart Report"` | Report title shown on the first page. |
| `Subtitle` | `string?` | `null` | Optional subtitle shown below the title. `null` means no subtitle. |

### Page Layout

| Property | Type | Default | Validation | Description |
|----------|------|---------|------------|-------------|
| `PageWidth` | `float` | `595f` (A4 width) | Must be `>= 100`; otherwise `ArgumentOutOfRangeException`. | Page width in points. |
| `PageHeight` | `float` | `842f` (A4 height) | Must be `>= 100`; otherwise `ArgumentOutOfRangeException`. | Page height in points. |
| `Margin` | `float` | `40f` | Must be `>= 0`; otherwise `ArgumentOutOfRangeException`. | Uniform margin applied on all four sides, in points. |

Default page size is A4 portrait (595 × 842 pt). Usable content width is `PageWidth - 2 * Margin`, which is 515 pt with the defaults.

### Typography

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `TitleFontSize` | `float` | `24f` | Title font size in points. |
| `HeadingFontSize` | `float` | `16f` | Section heading font size in points. |
| `BodyFontSize` | `float` | `11f` | Body text font size in points. |

No validation is applied to the font sizes. Non-positive values are accepted by the class itself; how the generator handles them depends on the rendering code.

### Chart Rendering

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `ChartDpi` | `int` | `150` | Resolution used when rasterising chart images for the PDF. Higher values give sharper charts and larger files. |

### Footer

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `ShowPageNumbers` | `bool` | `true` | When `true`, a page number footer is added to each page. |

### Colours

Colours are hex strings (for example `"#FFFFFF"`). No validation is performed in the options class.

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `PageBackgroundColor` | `string` | `"#FFFFFF"` | Background colour of each page (white). |
| `TextColor` | `string` | `"#1A1A1A"` | Primary text colour (near-black). |
| `AccentColor` | `string` | `"#2E7D99"` | Colour for headings and rules. |

## Usage

```csharp
var options = new PdfReportOptions
{
    Title = "Quarterly Metrics",
    Subtitle = "Generated automatically",
    PageWidth = 842f,   // A4 landscape
    PageHeight = 595f,
    Margin = 50f,
    ChartDpi = 300,
    AccentColor = "#C0392B"
};
```

Setting `PageWidth`, `PageHeight` or `Margin` to an out-of-range value throws immediately:

```csharp
var options = new PdfReportOptions();
options.Margin = -1f;   // throws ArgumentOutOfRangeException ("Margin cannot be negative.")
options.PageWidth = 50f; // throws ArgumentOutOfRangeException ("PageWidth must be at least 100 pt.")
```

## Notes

- Page dimensions are not validated against the margin. A large `Margin` on a small page can leave no usable content area.
- `ChartDpi` has no range check. Very large values increase render time and memory use.
- Colour strings are not parsed here. An invalid hex value is only detected when the generator uses it.
- Related types: `PdfReportGenerator` consumes this class; `ReportSection` and `PdfImageFit` (both in the same file) describe per-section content and image scaling.
