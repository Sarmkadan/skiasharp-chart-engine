# EventDispatcherJsonExtensions

> **Status: source file removed.** `Events/EventDispatcherJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `EventDispatcher` in the `SkiaSharpChartEngine.Events` namespace. The extensions convert an `EventDispatcher` instance to a JSON string and back, using camelCase property names and no indentation by default.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, built from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`.
- `ReferenceHandler` set to `ReferenceHandler.IgnoreCycles`.

The class is declared as `public static class EventDispatcherJsonExtensions`.

## API

### `public static string ToJson`

Serializes an `EventDispatcher` instance to a JSON string. When `indented` is `true`, the method serializes with a copy of the shared options that has `WriteIndented` enabled. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`EventDispatcher`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation for readability (default: `false`).

**Return Value**
- `string`: The JSON representation of the `EventDispatcher`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static EventDispatcher? FromJson`

Deserializes a JSON string to an `EventDispatcher` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `EventDispatcher?`: The deserialized instance, or `null` if `json` is empty or whitespace.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `JsonException`: Thrown when the JSON is invalid or cannot be deserialized.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to an `EventDispatcher` instance. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`EventDispatcher?`, `out`): Set to `null` at the start of the call. Receives the deserialized instance when deserialization succeeds.

**Return Value**
- `bool`: `true` if `json` is non-empty and deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.

---

## Usage

```csharp
using SkiaSharpChartEngine.Events;

var dispatcher = new EventDispatcher(logger);

string compact = dispatcher.ToJson();
string indented = dispatcher.ToJson(indented: true);

EventDispatcher? restored = EventDispatcherJsonExtensions.FromJson(compact);

if (EventDispatcherJsonExtensions.TryFromJson(indented, out var parsed))
{
    // use parsed
}
```

## Notes

- `EventDispatcher` has no parameterless constructor. Its only constructor takes an `ILogger<EventDispatcher>`, and the subscriber lists hold `IEventHandler` instances. The round trip is therefore not expected to work with the default `System.Text.Json` contract: deserialization would have to fail with a `JsonException`, which `FromJson` propagates and `TryFromJson` turns into `false`. This was not verified by running the code, because the source file no longer exists.
- Because the source was removed, `ToJson` and `FromJson` cannot be called from the current codebase. Any caller must restore the file or implement the helpers elsewhere.
