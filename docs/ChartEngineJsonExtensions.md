# ChartEngineJsonExtensions

> **Status: source file removed.** `ChartEngineJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `ChartEngine` in the root `SkiaSharpChartEngine` namespace. The extensions convert a `ChartEngine` instance to a JSON string and back, using camelCase property names and a `$type` discriminator for polymorphic type information.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, built from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- A `DefaultJsonTypeInfoResolver` modifier that sets `PolymorphismOptions` on the `ChartEngine` type info, with `TypeDiscriminatorPropertyName` set to `"$type"`.

## API

### `public static string ToJson`

Serializes a `ChartEngine` instance to a JSON string. When `indented` is `true`, the method serializes with a copy of the shared options that has `WriteIndented` enabled. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`ChartEngine`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the `ChartEngine`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static ChartEngine? FromJson`

Deserializes a JSON string to a `ChartEngine` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `ChartEngine?`: The deserialized instance, or `null` if the JSON represents a null value.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty or whitespace.
- `JsonException`: Thrown when the JSON is invalid or cannot be deserialized.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to a `ChartEngine` instance. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`ChartEngine?`, `out`): Receives the deserialized instance, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty or whitespace.

---

## Usage

```csharp
using SkiaSharpChartEngine;

var engine = ChartEngine.Create();

string compact = engine.ToJson();
string indented = engine.ToJson(indented: true);

ChartEngine? restored = ChartEngineJsonExtensions.FromJson(compact);

if (ChartEngineJsonExtensions.TryFromJson(indented, out var parsed))
{
    // parsed is the deserialized instance
}
```

## Notes

- `ToJson` and `FromJson` are the only public entry points. Whitespace-only input to `FromJson` and `TryFromJson` throws `ArgumentException` and is not treated as a failed parse.
- `TryFromJson` only handles `JsonException`. Argument validation errors still propagate.
- The `$type` discriminator is configured only for `ChartEngine`. Other types use default serialization.
