# ReportSectionJsonExtensions

> **Status: source file removed.** `Reports/ReportSectionJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `ReportSection` in the `SkiaSharpChartEngine.Reports` namespace. The extensions convert a `ReportSection` instance to a JSON string and read one back, using camelCase property names.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, created from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `TypeInfoResolver` set to a new `DefaultJsonTypeInfoResolver`. This is reflection-based metadata, so the helpers are not compatible with trimmed or AOT-published output without a source-generated context.

No enum converter is configured. `ImageFit` (a `PdfImageFit`) is written as its integer value, not as a name.

`ReportSection` has these serialized properties: `heading`, `bodyText`, `chart`, `imageFit`, and `pageBreakBefore`. The `chart` property is a `Chart` and is serialized through the same default resolver. The source does not special-case it, so serialization of a chart that cannot be represented in JSON can throw an exception other than `JsonException` (for example `NotSupportedException`), and `FromJson` and `TryFromJson` do not catch it. This was not covered by tests in the removed version.

## API

### `public static string ToJson`

Serializes a `ReportSection` instance to a JSON string. When `indented` is `true`, it serializes with a new copy of the shared options with `WriteIndented` set to `true`. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`ReportSection`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the `ReportSection`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static ReportSection? FromJson`

Deserializes a JSON string to a `ReportSection` instance. Unlike the `AnimationSettings` helpers, this method does not throw on malformed input.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `ReportSection?`: The deserialized instance, or `null` if deserialization fails. Empty, whitespace-only, invalid, and literal `null` input all return `null`, because `System.Text.Json` reports them as `JsonException`, which is caught.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to a `ReportSection` instance. Catches `JsonException` and reports failure through the return value.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`ReportSection?`, `out`): Receives the deserialized instance, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization completes without a `JsonException`; otherwise, `false`.

  Note that the literal `null` JSON value is treated as success. `TryFromJson("null", out var v)` returns `true` with `v` set to `null`. Check `value` for `null` as well as the return value.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.

---

## Usage

`ToJson` is an extension method, so it is called on an instance. `FromJson` and `TryFromJson` are static methods on the class and are called through it.

```csharp
using SkiaSharpChartEngine.Reports;

var section = new ReportSection
{
    Heading = "Quarterly Revenue",
    BodyText = "Revenue grew in every region.",
    PageBreakBefore = true,
};

string compact = section.ToJson();
string indented = section.ToJson(indented: true);

ReportSection? restored = ReportSectionJsonExtensions.FromJson(compact);

if (ReportSectionJsonExtensions.TryFromJson(compact, out var parsed) && parsed is not null)
{
    Console.WriteLine(parsed.Heading);
}
```
