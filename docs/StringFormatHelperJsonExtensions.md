# StringFormatHelperJsonExtensions

> **Status: source file removed.** `Utilities/StringFormatHelperJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` helpers for `StringFormatHelper`. The extensions convert a `StringFormatHelper` instance to a JSON string and read one back, using camelCase property names.

`StringFormatHelper` is a stateless utility class: every public member is `static`, and it has no instance fields. The JSON helpers therefore carry no data. For the helper's actual methods (number, currency, and percentage formatting, truncation, case conversion, sanitization, CSV lines, and so on), see [StringFormatHelper](StringFormatHelper.md).

## Build status when the file existed

The file lived in `Utilities/`, which is not excluded from compilation in `skiasharp-chart-engine.csproj`, so it was built with the rest of the library. `StringFormatHelper` is in the same `SkiaSharpChartEngine.Utilities` namespace, so no `using` directive was needed.

Nothing in the current source tree calls `ToJson`, `FromJson`, or `TryFromJson` on `StringFormatHelper`. Removing the file did not affect any caller.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance built from `JsonSerializerDefaults.Web` with `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`. `JsonSerializerDefaults.Web` also makes property matching case-insensitive and allows trailing commas, but neither setting matters here because there are no properties to match.

`WriteIndented` is off by default. No `TypeInfoResolver` is set, so the default reflection-based resolver is used. The helpers are therefore not compatible with trimmed or AOT-published output without a source-generated context.

## API

### `public static string ToJson`

Serializes a `StringFormatHelper` instance to a JSON string. The output is an object with a single `type` property holding the type name. When `indented` is `true`, it serializes with a new copy of the shared options with `WriteIndented` set to `true`. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`StringFormatHelper`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation, for example `{"type":"StringFormatHelper"}`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static StringFormatHelper? FromJson`

Validates a JSON string and returns a new `StringFormatHelper` instance. The JSON content is not used to build the instance, because the class has no state.

**Parameters**
- `json` (`string?`): The JSON string to validate.

**Return Value**
- `StringFormatHelper?`: A new instance if `json` parses as JSON, or `null` if `json` is `null` or empty.

**Exceptions**
- `JsonException`: Thrown when `json` is not valid JSON. This includes whitespace-only input, which is not null or empty and therefore reaches the parser.

Because the parser is called with `Deserialize<object>`, the literal `null` is valid JSON. `FromJson("null")` therefore returns a new instance, not `null`. Only the empty-string and `null`-argument cases return `null`.

---

### `public static bool TryFromJson`

Attempts to validate a JSON string and return a new `StringFormatHelper` instance. Catches `JsonException` and reports failure through the return value.

**Parameters**
- `json` (`string`): The JSON string to validate. Cannot be null or empty.
- `value` (`StringFormatHelper?`, `out`): Receives the new instance on success. It is `null` when the method returns `false`.

**Return Value**
- `bool`: `true` if `json` parses as JSON; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty. This check happens before the `try` block, so it is not caught.

---

## Usage

`ToJson` is an extension method, so it is called on an instance. `FromJson` and `TryFromJson` are static methods on the extensions class.

```csharp
var helper = new StringFormatHelper();

// Serialize
string json = helper.ToJson();              // {"type":"StringFormatHelper"}
string pretty = helper.ToJson(indented: true);

// Validate and recreate
StringFormatHelper? restored = StringFormatHelperJsonExtensions.FromJson(json);

if (StringFormatHelperJsonExtensions.TryFromJson(json, out var value))
{
    // value is a new, stateless StringFormatHelper
}
```
