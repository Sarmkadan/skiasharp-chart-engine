# WebhookHandlerJsonExtensions

> **Status: source file removed.** `Integration/WebhookHandlerJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for [`WebhookHandler`](WebhookHandler.md) in the `SkiaSharpChartEngine.Integration` namespace. The extensions convert a `WebhookHandler` instance to a JSON string and back, using camelCase property names.

The original file was excluded from the library build by `<Compile Remove="Integration/**/*.cs" />` in `skiasharp-chart-engine.csproj`, so these helpers never shipped in the compiled assembly.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, built from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`, so `null` properties are omitted from the output.
- `ReferenceHandler` set to `ReferenceHandler.IgnoreCycles`, so cyclic object graphs do not cause a serialization failure.
- `PropertyNameCaseInsensitive` set to `true`, so property names match regardless of case on input.

## API

### `public static string ToJson(this WebhookHandler value, bool indented = false)`

Serializes a `WebhookHandler` instance to a JSON string. When `indented` is `true`, the method serializes with a copy of the shared options that has `WriteIndented` enabled. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`WebhookHandler`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the `WebhookHandler`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static WebhookHandler FromJson(string json)`

Deserializes a JSON string to a `WebhookHandler` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `WebhookHandler`: The deserialized instance. Never `null`; a JSON `null` literal throws `JsonException`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty.
- `JsonException`: Thrown when the JSON is invalid, cannot be deserialized, or is the `null` literal.

---

### `public static bool TryFromJson(string json, out WebhookHandler value)`

Attempts to deserialize a JSON string to a `WebhookHandler` instance. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`WebhookHandler`, `out`): Receives the deserialized instance, or `default` (`null`) if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is empty.

---

## Usage

```csharp
using SkiaSharpChartEngine.Integration;

WebhookHandler handler = /* obtained from DI or constructed with an ILogger */;

string compact = handler.ToJson();
string indented = handler.ToJson(indented: true);

WebhookHandler restored = WebhookHandlerJsonExtensions.FromJson(compact);

if (WebhookHandlerJsonExtensions.TryFromJson(indented, out var parsed))
{
    // parsed is the deserialized instance
}
```

## Notes

- `ToJson` is an extension method; `FromJson` and `TryFromJson` are called on the static class.
- Whitespace-only input to `FromJson` and `TryFromJson` is not rejected by the argument check. It reaches the serializer and fails with `JsonException` (`FromJson`) or returns `false` (`TryFromJson`).
- `TryFromJson` only handles `JsonException`. Argument validation errors still propagate.
- `TryFromJson` returns `true` with a `null` value when the input is the JSON `null` literal, while `FromJson` throws for the same input. Callers that rely on a non-null result should check `value` after a `true` return.
- Deserialization depends on System.Text.Json being able to construct `WebhookHandler`. The class exposes only a constructor that takes `ILogger<WebhookHandler>`, and the original file did not register a custom converter or factory for it. Round-tripping was not verified by running the code, so treat `FromJson` and `TryFromJson` as likely to fail for this type unless that constructor is addressed.
- Serialization writes the public properties of `WebhookHandler` and its nested `WebhookOptions`. Fields and private state are not written.
- See [WebhookHandler](WebhookHandler.md) for the type itself.
