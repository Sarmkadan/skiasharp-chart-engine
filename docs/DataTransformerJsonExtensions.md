# DataTransformerJsonExtensions

> **Status: source file removed.** `Utilities/DataTransformerJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `DataTransformer` in the `SkiaSharpChartEngine.Utilities` namespace. The extensions convert a `DataTransformer` instance to a JSON string and read one back, using camelCase property names and omitting `null` values.

The helpers are of little practical use. `DataTransformer` keeps its only state in a private `ILogger<DataTransformer>` field and exposes no public properties. Its public members are methods (`NormalizeValues`, `ApplyLogTransformation`, `FilterOutliers`, `ApplyMovingAverage`, `ScaleValues`, `OffsetValues`, `RankDataPoints`). The JSON form is therefore always an empty object, and deserialization cannot rebuild a working instance because the class has no parameterless constructor (see [Notes](#notes)).

For the transformer itself, see [DataTransformer](DataTransformer.md).

## Build status when the file existed

The file was compiled into the library. `Utilities/DataTransformer.cs` is still compiled in the current project (its `<Compile Remove>` entry in `skiasharp-chart-engine.csproj` is commented out), so the extension class would have compiled against it. ## Configuration

The extensions share a single private `JsonSerializerOptions` instance built from `JsonSerializerDefaults.General`, with these overrides:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`.
- `WriteIndented` set to `false`.

No `TypeInfoResolver` is set, so the default reflection-based resolver is used. The helpers are therefore not compatible with trimmed or AOT-published output without a source-generated context.

## API

### `public static string ToJson(this DataTransformer value, bool indented = false)`

Serializes a `DataTransformer` instance to a JSON string. When `indented` is `true`, it serializes with a new copy of the shared options with `WriteIndented` set to `true`. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`DataTransformer`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation. Because the class has no public properties, this is always `{}`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static DataTransformer? FromJson(string json)`

Deserializes a JSON string to a `DataTransformer` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `DataTransformer?`: `null` when `json` is an empty string. Otherwise, the result of `JsonSerializer.Deserialize<DataTransformer>`. In practice, deserialization does not produce a usable instance (see [Notes](#notes)).

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `JsonException`: Thrown by `System.Text.Json` when the JSON is invalid. This includes whitespace-only input, which is not trimmed before it is passed on.
- `InvalidOperationException`: Thrown by `System.Text.Json` for a type with no usable constructor. It is not caught.

---

### `public static bool TryFromJson(string json, out DataTransformer? value)`

Attempts to deserialize a JSON string to a `DataTransformer` instance. Catches `JsonException` and reports failure through the return value.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`DataTransformer?`, `out`): Receives the deserialized instance. It is set to `null` before any work is done, and stays `null` when the method returns `false`.

**Return Value**
- `bool`: `false` when `json` is an empty string or when `JsonException` is caught; otherwise, `true`. A `true` result does not guarantee a non-null `value`. JSON `null` deserializes to `null` and still returns `true`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `InvalidOperationException`: Propagates from `System.Text.Json` for the same reason as `FromJson`. It is not caught.

---

## Usage

```csharp
using Microsoft.Extensions.Logging;
using SkiaSharpChartEngine.Utilities;

ILogger<DataTransformer> logger = /* resolved from DI or an ILoggerFactory */;
DataTransformer transformer = new(logger);

string compact = transformer.ToJson();
string indented = transformer.ToJson(indented: true);

DataTransformer? restored = DataTransformerJsonExtensions.FromJson(compact);

if (DataTransformerJsonExtensions.TryFromJson(indented, out var parsed))
{
    // parsed may still be null; check before use
}
```

## Notes

- `ToJson` is an extension method on the instance. `FromJson` and `TryFromJson` are static methods on the `static` class, so call them as `DataTransformerJsonExtensions.FromJson(...)`.
- `DataTransformer` has one constructor, which takes `ILogger<DataTransformer>`, and no parameterless constructor. `System.Text.Json` cannot bind that parameter to any JSON property, so deserialization is not expected to succeed. This was determined by reading the type, not by running a round-trip test.
- Because the logger is a private field and the transform methods are not serialized, no transformer state survives a round trip.
- The empty-string case in `FromJson` returns `null` without calling `System.Text.Json`. The whitespace-only case does not, and reaches `JsonException`. The two cases are handled differently.
- `TryFromJson` returns `false` for empty input without attempting deserialization, which is why its empty-input result differs from `FromJson`.
