# BinaryChartSerializerJsonExtensions

> **Status: source file removed.** `Serializers/BinaryChartSerializerJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` helpers for `BinaryChartSerializer`. The extensions convert a `BinaryChartSerializer` instance to a JSON string and read one back, using camelCase property names.

The helpers were never useful for persisting chart data. `BinaryChartSerializer` keeps no public state (its only field is a private `ILogger`), so the JSON form is always an empty object. For the real binary round-trip of a `Chart`, see [BinaryChartSerializer](BinaryChartSerializer.md).

## Build status when the file existed

The project file excludes the whole folder from compilation with `<Compile Remove="Serializers/**/*.cs" />`, so this file was never built. It also declared `namespace SkiaSharp.Chart.Engine.Serializers;`, which does not match the `SkiaSharpChartEngine.Serializers` namespace of `BinaryChartSerializer`. Even if it had been included, it would not have resolved the class without a `using` directive.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, created from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`.

No `TypeInfoResolver` is set, so the default reflection-based resolver is used. The helpers are therefore not compatible with trimmed or AOT-published output without a source-generated context.

## API

### `public static string ToJson`

Serializes a `BinaryChartSerializer` instance to a JSON string. When `indented` is `true`, it serializes with a new copy of the shared options with `WriteIndented` set to `true`. Otherwise it uses the shared options directly.

**Parameters**
- `value` (`BinaryChartSerializer`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation. Because the class has no public properties, this is always `{}`.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static BinaryChartSerializer? FromJson`

Deserializes a JSON string to a `BinaryChartSerializer` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `BinaryChartSerializer?`: The deserialized instance, or `null` if `json` is empty or the literal JSON value `null`.

**Exceptions**
- `JsonException`: Thrown when `json` is not valid JSON.
- `InvalidOperationException`: Thrown for a valid JSON object such as `{}`. The class has no parameterless constructor, and the constructor parameter (`ILogger<BinaryChartSerializer>`) cannot bind to any JSON property, so System.Text.Json rejects the type.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to a `BinaryChartSerializer` instance. Catches `JsonException` and reports failure through the return value.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`BinaryChartSerializer?`, `out`): Receives the deserialized instance, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization completes without a `JsonException`; otherwise, `false`.

  As with `FromJson`, the literal `null` is treated as success, and `TryFromJson("null", out var v)` returns `true` with `v` set to `null`. A valid object such as `{}` is not caught, so `InvalidOperationException` propagates out of this method.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `InvalidOperationException`: Thrown for a valid JSON object such as `{}` (see `FromJson`).

---

## Usage

`ToJson` is an extension method, so it is called on an instance. `FromJson` and `TryFromJson` are static methods on the class and are called through it.

```csharp
using SkiaSharpChartEngine.Serializers;

var serializer = new BinaryChartSerializer(logger);

string compact = serializer.ToJson();          // "{}"
string indented = serializer.ToJson(indented: true);

BinaryChartSerializer? restored = BinaryChartSerializerJsonExtensions.FromJson(compact); // throws, see above
```

Do not rely on `FromJson` or `TryFromJson` to rebuild a `BinaryChartSerializer` from `{}`. Create the instance with its logger instead, and use `SerializeAsync` and `DeserializeAsync` to move `Chart` data.
