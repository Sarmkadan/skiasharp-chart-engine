# AnimationSettingsJsonExtensions

> **Status: source file removed.** `Models/AnimationSettingsJsonExtensions.cs` was deleted from the repository in commit `ee7b83f` ("fix: remove junk JsonExtensions files generated by engines"). It is not part of the current source tree or the build. This document describes its last committed version (`ee7b83f^`) and is kept for reference only.

Provides `System.Text.Json` serialization helpers for `AnimationSettings` in the `SkiaSharpChartEngine.Models` namespace. The extensions convert an `AnimationSettings` instance to a JSON string and read one back, using camelCase property names.

## Configuration

The extensions share a single private `JsonSerializerOptions` instance, created from `JsonSerializerDefaults.Web` with:

- `PropertyNamingPolicy` set to `JsonNamingPolicy.CamelCase`.
- `WriteIndented` set to `false`.
- `DefaultIgnoreCondition` set to `JsonIgnoreCondition.WhenWritingNull`. `AnimationSettings` has no nullable properties, so this setting has no effect on its output.

No enum converter is configured. `EasingType` (an `EasingFunction`) is written as its integer value, not as a name.

## API

### `public static string ToJson`

Serializes an `AnimationSettings` instance to a JSON string. It always serializes with a copy of the shared options, with `WriteIndented` set to the value of `indented`.

**Parameters**
- `value` (`AnimationSettings`, `this`): The instance to serialize.
- `indented` (`bool`, optional): Whether to format the JSON with indentation (default: `false`).

**Return Value**
- `string`: The JSON representation of the `AnimationSettings`, with `enabled`, `durationMs`, `frameRate`, `easingType`, `animateOnLoad`, `animateOnUpdate`, `startOpacity`, and `endOpacity` properties.

**Exceptions**
- `ArgumentNullException`: Thrown when `value` is `null`.

---

### `public static AnimationSettings FromJson`

Deserializes a JSON string to an `AnimationSettings` instance.

**Parameters**
- `json` (`string`): The JSON string to deserialize.

**Return Value**
- `AnimationSettings`: The deserialized instance. Never `null`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is an empty string.
- `JsonException`: Thrown when `json` is whitespace, is invalid JSON, or is the literal `null`. The literal `null` is reported as a `JsonException` because the method throws when the deserialized value is `null`.

---

### `public static bool TryFromJson`

Attempts to deserialize a JSON string to an `AnimationSettings` instance. Catches `JsonException` and reports failure through the return value instead of throwing.

**Parameters**
- `json` (`string`): The JSON string to deserialize.
- `value` (`AnimationSettings?`, `out`): Receives the deserialized instance, or `null` if deserialization fails.

**Return Value**
- `bool`: `true` if deserialization succeeds; otherwise, `false`.

**Exceptions**
- `ArgumentNullException`: Thrown when `json` is `null`.
- `ArgumentException`: Thrown when `json` is an empty string.

---

## Usage

```csharp
using SkiaSharpChartEngine.Models;

var settings = new AnimationSettings(750, 30) { StartOpacity = 0.25 };

string compact = settings.ToJson();
string indented = settings.ToJson(indented: true);
// compact: {"enabled":true,"durationMs":750,"frameRate":30,"easingType":3,"animateOnLoad":true,"animateOnUpdate":true,"startOpacity":0.25,"endOpacity":1}

AnimationSettings restored = AnimationSettingsJsonExtensions.FromJson(compact);

if (AnimationSettingsJsonExtensions.TryFromJson(indented, out var parsed))
{
    Console.WriteLine(parsed.DurationMs); // 750
}
```

## Notes

- **Round-trip works.** `AnimationSettings` has a public parameterless constructor, so `System.Text.Json` deserializes it without extra attributes. A probe that compiled the last committed `AnimationSettings.cs` and `AnimationSettingsJsonExtensions.cs` in a scratch project outside the repository confirmed that `DurationMs`, `FrameRate`, `EasingType`, and `StartOpacity` survive `ToJson` followed by `FromJson`.
- **`EasingType` is numeric.** `EasingFunction` has no string converter, so `EaseInOutQuad` is written as `3`. Changing an `EasingFunction` member's position in the enum changes the stored value. Adding a `JsonStringEnumConverter` would change the output format, so it should be a separate change.
- **Validation is not performed.** `FromJson` and `TryFromJson` do not call `AnimationSettings.Validate()`. Out-of-range values such as a negative `DurationMs`, a `FrameRate` below 1, or opacity outside 0–1 deserialize without error. Call `Validate()` on the result if the input is untrusted.
- **Whitespace input is a `JsonException`.** `ArgumentException.ThrowIfNullOrEmpty` checks only for `null` and empty strings. A whitespace-only string passes that check, and the serializer then throws `JsonException`. `TryFromJson` does not catch the `ArgumentException` for an empty string, so it throws rather than returning `false`.
- **`TryFromJson` returns `false` for the literal `null`.** The deserialized value is `null`, so the method reports failure. `FromJson` throws `JsonException` in the same case.
